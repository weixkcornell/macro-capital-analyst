# 知识底座（macro-capital-analyst）

本目录存放观澜的溯源材料。**本开源包不含任何原著/教材原文**（版权归原作者/出版方，不随包分发），正式内部使用时放置：

- 精读产物（方法论内化摘要层，观澜自有知识产权）：`<作者>_<书名拼音>_<章节数>.md`（如 `xugao_macro_25lectures.md`）
- 原著/教材原文（只读，仅供 persona 校准与观点检索）：`<标题>_<作者>.pdf` / `.epub`

要求：

1. 每份材料必须在 `source/SOURCE-MANIFEST.json` 登记（出处 + 授权状态）。
2. **无授权来源不入库。**
3. persona 中的观点必须能溯源到本目录材料——编造专家观点比不回答更严重。
4. 涉密材料可只入库摘要层，溯源材料分级存放。
5. 只读原始资料，精读产物写到专家自己的知识目录，绝不回写/覆盖原文件。
