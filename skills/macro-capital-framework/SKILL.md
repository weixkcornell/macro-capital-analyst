# 宏观与资本市场分析工艺（macro-capital-framework）

> 一句话总纲：先定基准、结论先行、层层递进、逐条可核验；无测算不下结论，净预期主动收益 ≤ 0 不发布。

- 输出骨架：`output-templates/a-share-outlook.json` / `cycle-positioning.json`。

## §1 行文逻辑（怎么写）

1. **先定基准（第 0 层，总开关）**：落笔前先明确本期基准（沪深300，价格指数口径）与有效主动风险预算额度；**没有基准，一切超配/低配都是没有度量单位的形容词**。基准口径三声明：价格指数≠全收益（低估股息，不得记为 α）、现金是约束代价非判断失误、口径不得事后切换。
2. **结论先行**：开篇给一句话判断，再展开证据；每个判断挂一个量化锚。
3. **层层递进不罗列**：观点之间呈现推导关系，每层结尾给「本层结论」并自然引出下一层；禁止「观点 A；观点 B；观点 C」式的罗列。
4. **六步组织**：市场观点类产出按「钱从哪来 → 钱变利润 → 价格装多少预期 → 结构定价自洽 → 周期定位风险归属 → 错了会怎样」递进。
5. **方法论内化**：正文不得出现书名、作者名、「某书认为」等书目痕迹；方法只用于判断，不作为可见内容。文末「方法论说明」只描述本人分析流程。
6. **两个强制独立章节**：市场观点类产出必须含「上期判断回顾」（逐条标注已验证/未验证/证伪 + 累计命中率，不用短期损益贴标签）与「方法可靠性声明」（显式声明局限）。
7. **主动收益落账（v34 起口径）**：任何偏离须写成主动权重向量 w_a（Σw_a,i=0），用协方差口径 σ_A 精算，并按**基本成分三分解**给出 E[R_A] 与净预期主动收益——**禁止只给方向不给数**。
8. **十三层并用（验收标准）**：① 十三层**并用**（不是挑几层）；② 每层取到**可核验机制**（不是贴概念标签）；③ **两道横切闸门任一不过 = 不合格**。其中 ⑩⑪⑫⑬ 为**按需层**：结论涉及模型可信性、极端风险、机构行为或仓位杠杆时，必须先过对应层再落笔。

    - **凭据缺失 fail-closed（v2.8.1 补 · 与上条同源）**：若 Wind CLI 因未配置凭据返回 `AUTH_ERROR` / `CREDENTIAL_MISSING`，须如实报「通道不可用」＋**已试凭据路径**（`~/.wind-aifinmarket/config` → skill `config.json` → 环境变量 `WIND_API_KEY`）＋错误码，并连同**本期实际档位**一并写入「方法可靠性声明」；**禁止以重装 skill/provider 作为修法、禁止绕走 `analytics_data` / `wind-alice`、禁止静默降级**。降级通道（westock → 公开接口自算 → 外部口径）的每个数字须**逐项标注降级理由与来源**。门禁 `wind-provenance`（执行工具 `<pack>/scripts/check-wind-provenance.py`，含 `--selftest` 自校准：2 正向 + 3 反向）。
    - **移动端可读性（v2.8.1 补）**：交付 HTML 须过 `mobile-readability` —— 375 主视口（覆盖 320/390）正文 ≥17px、图内文字**等效字号** ≥11px（＝font-size × 视口宽/viewBox 宽）或提供点击全屏入口、触控目标 ≥44px、宽表卡片堆叠或受控横滚、页面级 0 溢出与 0 裁切重叠。规格见 `output-templates/*.json` 的 `renderModes.html.mobile`；执行工具 `<pack>/scripts/audit-mobile.py`。
    - **Wind CLI 调用示例（v2.8.3 补 · 可直接复制）**：**先取码、再取数** —— ① `HOME=<凭据用户家目录> node /root/.agents/skills/wind-mcp-skill/scripts/cli.mjs call economic_data search_economic_indicator '{"question":"沪深300指数收盘价"}'` → 返回 `M0342072`（代码用于**引用/溯源**）；② `HOME=<凭据用户家目录> node /root/.agents/skills/wind-mcp-skill/scripts/cli.mjs call economic_data query_economic_indicator_data '{"question":"沪深300指数收盘价","beginDate":"2026-09-01","endDate":"2026-09-30"}'` → 返回日频时序。**字段真相（2026-09-30 实测）**：`query_economic_indicator_data` **只收 `question`**（+可选 `beginDate`/`endDate`/`observation`/`targetMagnitude`/`targetCurrency`/`targetFrequency`），**不收 `indicator_code`**（传即 `PARAM_VALIDATION_ERROR`）；**`HOME` 会影响凭据解析** —— CLI 按 `homedir()` 找 `~/.wind-aifinmarket/config`，HOME 不指向凭据所在家目录时会误报 `AUTH_ERROR`。字段真相存于 `data-contracts/wind-tool-schemas.json`（由 `list-tools` 记录）；**发布前由 `node <pack>/scripts/check-doc-commands.mjs` 离线校验「文档/契约里写的字段 ⊆ 真实 inputSchema」** —— 该门正是为 v2.8.1 那次「把 indicator_code 当入参、文档命令跑不通」的缺陷而补。

1. **口径锚定**：宏观数字先读对——名义/实际、同比/环比、结构拆解、基数与季节性；锚定官方口径。
2. **四级数据标注**：每个非引用数字必须落到一级——`测算`（模型算，给参数）/ `估算`（量级推断）/ `研判推断`（分析性判断）/ `待补`（进观察清单）。
3. **来源可点击**：引用数据/观点挂来源链接，严禁编造；券商观点只作对照组，给出「认同/保留/反对及理由」。
4. **一手自算**：行情用公开 K 线自算四档分位、波动、回撤、相关矩阵、拥挤度（三条口径：成交额占比/持有人结构/收益同步）、风险贡献分解；估值分位若用外部口径必须标注来源。
5. **实施成本五度量法**：佣金 + 买卖价差 + 价格冲击（平方根律，主导项）+ 延迟/机会成本 + 税费，落账用 IS=TC+OC；**只算佣金 = 未通过**。
6. **海外锚重标定**：海外实证数值只作数量级参考，A 股须重新标定，严禁当默认判据。
7. **铁律：编数字比不回答更严重**；数据不可得 → 如实标「待补」进观察清单。
8. **量纲与口径交叉校验**：外部行情/金融数据字段用于绝对额结论前，必须先与权威口径做比例校验；同一字段比例漂移 >5% 时，绝对额一律改用交易所/官方口径，外部字段只用于比值、分位和方向判断。
9. **收益口径折减（闸门 A 第 7 条）**：算术平均收益高估买入持有可获收益，差额 = 方差/2；A 股指数波动长期高于 20%，折减只会更大，**禁止沿用海外 2% 锚**。

## §3 质量门禁（怎么过关）

1. **两道横切闸门**（硬门，所有结论强制生效）：
   - **闸门 A · 统计可信（七条）**：① t 阈值按检验类型分档（时序回归 ≥3.8 / Fama-MacBeth ≥3.4 / 单向检验 ≥3.0，2.0 不可用）；② 同一数据多假设须做**多重检验校正（BH-FDR q=0.10 + Bonferroni）**并报「假设总数 / 原始 p<0.05 数 / 校正后存活数」，参数敏感性须 3 档阈值（85/90/95）同向；③ 样本 <10 年降级为提示性观察；④ 回测夏普按 **Haircut Sharpe + Deflated Sharpe 双口径**取较严者并披露四输入；⑤ **因子双锚**——正锚（发表偏误收缩仅 10–15%，FDR<10%）＋ 反锚（发表后衰减 50%+、拥挤与状态依赖）**成对报，缺一失真**；【红线】未过校正只写「证据不足，两个方向都不支持」，**禁止反向宣称因子无效/反向信号成立**；⑥ 胜率断言须同报原始/非重叠/月频单期重叠三类样本数；⑦ **收益口径折减与 p-hacking 拦截**——收益数字须声明几何/算术口径（算术须扣方差/2），研究须声明「假设登记在先、未调参」并披露调参次数与阈值档位，少于 30 个观测不单独下结论。**另有分层凯利**：下注上限 2P−1 的 P 按可预测性聚类取用，低可预测资产 P 收敛 0.50（上限 0）。
   - **闸门 B · 实施成本与可执行（六条）**：① 成本五度量法（佣金/价差/冲击/延迟/税费，IS=TC+OC），只算佣金 = 未通过；② ADV 容量 10% 与适用资金规模上限；③ 多空因子按不能做空折损 50%–60% 打折；④ 拥挤度三条口径极端时附退出触发条件；⑤ **主动风险须在事前档位额度内（协方差口径精算，禁止简单加总）**，超额度只能缩幅度或降级观察，另须报 N_eff 与 ρ̄；⑥ **杠杆水位与生存约束**——含仓位/杠杆的结论须声明自身杠杆上限（κ 取 2–3）、触发式止损在极端时的失效（A 股 T+1 + 涨跌停加剧）、以及「正确但被强平」风险与缓冲额度；崩盘识别用杠杆水位而非价格跌幅。末期硬要求：`E[R_A] __ bp − 实施成本 __ bp = 净预期主动收益 __ bp`，**没有这个数该条建议不发布**。
2. **起步门禁**（见 `quality-policies/baseline.json`）：禁例 token 0 命中（含语言硬规则）、占位符 0 残留、数字逐 token 一致、渲染 0 溢出 + 对比度 AA、排版审计 0 问题、章节大纲对照输出模板、配置结论净预期主动收益 > 0。；**Wind 取数档位与凭据 fail-closed（`wind-provenance`）**；**移动端可读性（`mobile-readability`）**；**输出模板一致性（`template-conformance`，见 §3.1）**
3. **摘要—正文—底座三方对撞**：摘要中的每条概括必须在正文找到对应论据、并在数据底座找到同口径证据；三方不一致时不得发布，先回底座查错。参考实现：`references/scripts/i1_collision_check.py`。
4. **合规红线**：对外匿名呈现（领域·首字母）；文末固定「不构成投资建议」；未发布官方数据显式标注「尚未发布」；渲染产物发布为公网外链前，先确认内容不涉密、可公开；A 股因子实证基线窗口 2000-01~2019-12 须标注并声明滚动复核。
5. **交付前逐项过** `references/checklist-template.md`。

## §3.1 输出模板与渲染契约（v2.8.4 起 · 强制）

**版式归模板，内容归作者。** 渲染器 `<pack>/scripts/render-report.mjs` 是**通用执行器**（token + 指令驱动），不内置任何版式；要改观感就改输出模板的 `designSystem`，不要改渲染器，更**不要在交付目录里另写一套一次性渲染脚本**（v1 的实况：真正决定质感的是一个 82KB 的硬编码脚本，模板沦为空文）。

1. **模板即契约**：`output-templates/*.json` 的 `designSystem` 声明 `tokens`（染色中性色阶／1.2 模数字号阶／4px 间距阶／染色投影／圆角）、`roles`（每条含对比度下限，由 token 值重算）、`components`（DOM 结构 + 类名 + 可选类）、`figures`（画布与图型白名单）、`print`、`a11y`；`directives` 声明允许的组件指令。**同包各模板的核心 token 必须一致**（一个包一个视觉身份）。
2. **作者只写 markdown**：组件一律用 `:::` 围栏声明，**不得在内容里写原始 HTML**（渲染器会 fail-closed）。未声明的指令名一律渲染失败。
3. **指令清单与行格式**（判据在模板 `directives.list`，此处为速查）。**register = 移动端杂志**：封面 → 导语 → 每章（章节开场 → 读懂这一节 → 正文与图）→ 术语表 → 脚注。
   - **封面三件**（相邻书写即合成一个全出血深底容器）：
     - `:::cover` — 头部 `kicker=`/`issue=`/`title=`/`lede=`；body 每行 `键 | 值`（基准、asOf、生成日…）。刊期用 hero 档大字（金色）。
     - `:::cover-stats` — 每行 `标签 | 值(含单位) | tone | 注释`，**最多 3 张**，且必须与内页同口径同值。
     - `:::cover-art` — body 每行 `日期 | 数值`，**必须是真实序列**（本期用基准近 60 个交易日）；无数据则整块不写。
   - `:::lede` — 导语（2–3 句，一句话说清本期结论）。
   - `:::takeaway` — **「读懂这一节」**：每章一处、2–3 条**大白话**（每条 ≤40 字、不用未解释的缩写），只做翻译，**不得引入正文没有的新数字或新结论**。
   - `:::glossary` — 术语表：每行 `术语 | 定义`，只解释本期真正出现的词。
   - `:::masthead` — 头部 `eyebrow=`/`title=`/`lede=`；body 每行 `键 | 值`（期次、基准、asOf、生成日…）。**报告名只放 title**，周期与基准另立角色，不得并入 h1。
   - `:::kpis` — 每行 `标签 | 值(含单位) | tone(neutral|up|down|warn) | 注释`。值里的**单位必须紧跟数字**；标签是名词短语、不是公式；同排最多一张高亮卡；卡数 %4==1 时末卡通栏。
   - `:::callout tone=conclusion|warning|caliber title=…` — body 为正文段。**不得嵌在卡片里**（双层边框）。
   - `:::quote` — 章眼金句，一句，每章至多一处。
   - `:::compare left=旧读法 right=新读法` — 每行 `维度 | 左 | 右`；旧读法弱、新读法强，靠明度差而非颜色。
   - `:::caliber` — 每行一条口径依据（左上「口径」徽标由 CSS 生成，内容里不写「口径」二字）。
   - `:::inferences` — 每行一条推论，**须含数字锚**。
   - `:::figure type=bars|diverging|range|waterfall|steps|matrix|sparkline|microbar|gauge|donut|pictogram|timeline title=… unit=… source=… [caption=…][qualitative=true][tone=sign]` — body 每行 `标签 | 数值`。**无数字不绘**；定性图加 `qualitative=true`（eyebrow 自动标「定性示意」）。图号由渲染器按 DOM 顺序连续重编号（eyebrow／figcaption／aria-label／id 四处同源）。`tone=sign` 仅在**确实是涨跌/正负方向**的读数上使用。
   - `:::no-figure` — 该章无数字时占位声明，不得画装饰图。
4. **颜色语义**：`--c-up/--c-down`（涨红跌绿）**只用于方向性读数**；净额、分位、波动、权重、偏离度等非方向性量化一律用墨色/青墨，否则是语义误读（且灰度打印下红绿不可辨，方向读数须同时带符号与文字）。
5. **交付前跑两条命令**（缺一不可）：
   - `<pack>/scripts/audit-delivery.sh --md <final.md> --html <index.html> --template <tpl.json> --pool <data-base.json>` —— **8 件**硬门（含本门的产物侧核对）。
   - `<pack>/scripts/check-template-conformance.mjs --template <tpl.json> --md <md> --html <html>` —— 模板一致性（tokens 取值逐字相同／组件类名齐备／禁 #fff-#000 底／禁档外字号／指令白名单）。
6. **迁移**：v2.8.4 之前的产物把组件硬编码在渲染脚本里；迁移方式是**按上表把组件改写成 `:::` 声明**，数字与结论一字不动（迁移只改渲染层，不改内容）。

## §4 跨著作权衡元判据（多派相左时怎么折中）

十三层之上不加层，加**判据**：同一问题常有多派互搏，落笔前先查「这里两派意见相左，取舍依据是什么」。

1. **风险三维分离**：波动率=运算代理（组合优化／协方差降维／风险预算）；期间风险（首次穿越，实测 80% 路径触及阈值 vs 期末仅 20%）＋ 尾部肥尾（±2σ 外面积比正态大 4–5 倍）=判断；流动性（危机是流动性事件而非信息事件，高能态下相关性绝对值趋近 1 且正负不可预测）=危机预警。三者分工，禁止用一个数同时承担三种角色。
2. **主动管理三判据**：零和（扣费前）＋ 平均无 α（扣费后；股票基金净 IR 0.12／毛 0.35，固收净 IR −0.87，费用是负 α 主因）＋ 持续性弱（IR 持续性系数股票 0.141、固收 0.368）→ 默认低费率指数/指增；「α 会变 β」是因子拥挤→超额消失的机理。海外锚，A 股经理 IR 分布未获取须本地实证。
3. **因子双锚**：正锚——发表偏误仅要求收缩 10–15%（FDR<10%），过 t>3.0 的真信号保留 85–90%；反锚——因子发表后收益衰减 50%+、拥挤与状态依赖进一步侵蚀。缺任一侧即失真。
4. **预期收益四问**：① 赚的是哪一类风险溢价 → ② 该溢价当前处于历史什么分位 → ③ 前瞻指标指向哪边 → ④ 扣掉实施成本与期限后净剩多少。缺项不得下结论。
5. **新兴市场禁用历史 ERP**：历史法 ERP 在新兴市场 complete failure，须改用隐含法（当前价格反推折现率 − 无风险利率）＋ 违约利差拼装；A 股 ERP 绝对数须本地重估。
6. **三问定位（周期定位的折中）**：结构定方向 → 时钟定状态 → 情绪定仓位（精度递增、确定性递减）；时钟是参考不是圣杯（A 股解释度仅 43–57%、时钟动量准确率 54–65%），商业周期择时有成本陷阱，只做温和偏移不做大幅择时。

**用法**：只在前述十三层与两道闸门之上作**折中依据**，不替代闸门判据、不新增能力层；所有实证数字均为海外/全球锚，A 股须本地重标定并显式声明。

## §5 主动收益：基本成分三分解与失效条款（v34/v35 · 现行唯一口径）

**为什么换口径（v34 的关键决定）**：曾按主动管理基础法则走 α = IC·z 路线。本机实测——29 条行业指数的**有效独立标的数只有 6.2**（标的间相对收益平均相关 ρ̄ = 0.132，N_eff = N/(1+(N−1)ρ̄)）⇒ 广度 BR ≈ 25 ⇒ 必须 IC 显著才撑得起 IR；而三个估值口径（自身历史分位／盈利收益率差／相对市盈率）的 IC **全部为负，且 BH-FDR 与 Bonferroni 存活均为 0**。指数层面的横截面没有足够的独立赌注，α 口径在本机**无法产出观点**。故分工：**「要不要下注」交给 IR = IC√BR 判据（用于否决）；「收益从哪来」交给可观测分量（用于给方向）**。

**三分解**：总收益 = ① 支付收益率（股息率＋净回购率）+ ② 预期现金流增长率（EPS 增长）+ ③ 预期估值变化（P/E 均值回归）。三项均可观测或可由公开数据算得，故本模块**不要求过 IC 显著性检验**。

- **①**：股息率由「全收益指数 − 价格指数」日收益差累计反推 TTM 口径；**净回购率本机未计**（A 股回购规模相对小），须标为**已知低估项**。
- **②**：由 E = P/PE 反推盈利序列后取复合增速；默认窗口 3 年，须同时输出 5 年作敏感性。
- **③**：以 dev = ln(PE / PE₁₀年中位数) 度量偏离；收敛速度不假定、由数据估得——对 dev 做年度采样 AR(1)，得半衰期 HL = ln0.5/lnρ，年化贡献 = −dev × (1 − 0.5^(1/HL))。**若 ρ ≥ 1（或无有效估计）→ ③ 记 0，并逐个标的标注「该标的无估值回归证据」。**

**两版并列（强制）**：A · 含③（①＋②＋③，情景参照）／B · 不含③（①＋②，稳健基准）。**只有两版同号的方向才可建仓**；异号者记「观察」并写明转同号的触发条件。

**与闸门 B 的接口**：格式串改三段式并标注成分来源——两版都要减实施成本、都要给「扣除后还剩多少 bp」；净预期主动收益 ≤ 0 的建议不发布。

**主动头寸失效条款（预登记，满足任一即触发）**：
1. **A · 累计负贡献**：某头寸连续 2 期已实现归因（扣实施成本后）为负，且累计净贡献 < −IC* → 降级「观察」、主动权重减半，下期不得加仓。
2. **B · 连续失效**：同一头寸连续 4 期净贡献为负 → 强制复盘，重跑成分检验（② 的窗口稳定性、③ 的 ρ 与半衰期是否漂移），对应成分结论不再成立则该成分归零。
3. **C · 映射被证伪（v34 重述）**：本地回测否证的**不是「股息会被支付」，而是「① 项可以单独作为唯一收益来源并据此放大仓位」**——用价格比值回归失败去否决股息支付属对象替换。故 ① 仍是三成分之一（可观测、须报），但单独不足以支撑建仓。
4. **D · ③ 的准入（v34 新增）**：③ 须逐个标的出示 dev、ρ、HL；**ρ ≥ 1 或无有效估计者 ③ 一律记 0**；两版异号的头寸不得建仓。

**每期动作**：登记 w_a 时须**同时登记**该头寸的累计已实现净贡献与连续失效期数（append-only，不事后改判）。

## §6 语言硬规则（v35 · 强制）

1. **去比喻化**：产出与内部文档一律不得用「腿」这一比喻称呼头寸、标的或口径——它把可核验的度量单位换成了身体隐喻，读者需要二次翻译。拥挤度的三个角度统一称**「三条口径」**（成交额占比／持有人结构／收益同步）。
2. **加粗只给数字与关键术语**，不得包整句判断。
3. **破折号只作「即／也就是」的补充**，不得代替冒号与句号。
4. **长句拆短**（一句一事）。
5. **豁免**：本规范与方法包自身须出现一次该字才能写出禁令；`banned-tokens` 门禁对该禁令句做定点裁剪。

## §7 按需层（⑩⑪⑫⑬）何时必须启用

| 层 | 触发条件 | 必须产出的东西 |
|:---|:---|:---|
| **⑩ 模型实证检验与诊断** | 任何**定价模型或 α 主张** | 声明所绑定的模型 m（换 m 即换 α）；三路等价中选了哪一路；宏观因子是否已造模拟组合；HJ 界是否给出排除结论 |
| **⑪ 风险边界与极端事件治理** | **极端情景、风控规则设定** | VaR 的操作性定义（99 天优化 + break 单独归因 + 交易前指定）；压力情景的**相对损失规模**（绝不给概率）；极端动作是否已在平静日预设 |
| **⑫ 信息不对称、微观结构与激励传导** | 涉及**行为／叙事／羊群／技术择时** | 交易对手与激励链（激励 → 行为 → 价格）；结论是否属**从业者经验**而非统计证据；涨跌不对称方向 |
| **⑬ 组合工程与生存约束** | 涉及**仓位／杠杆／止损／崩盘** | 自身杠杆上限与地板；止损 efficiency 折扣；「正确但被强平」的缓冲额度；崩盘监测用的是杠杆水位而非跌幅 |

**引用纪律**：⑫⑬ 两层的底本（Donnelly／Costello）为**从业者经验**，引用时必须标注，不得当作统计证据；⑩⑪ 的底本实证**全为海外市场**，无 A 股样本，须本地重标定。
