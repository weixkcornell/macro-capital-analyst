# 宏观与资本市场分析工艺（macro-capital-framework）

> 一句话总纲：先定基准、结论先行、层层递进、逐条可核验；无测算不下结论，净预期主动收益 ≤ 0 不发布。

- 输出骨架：`output-templates/a-share-outlook.json` / `cycle-positioning.json`。

## §1 行文逻辑（怎么写）

1. **先定基准（第 0 层，总开关）**：落笔前先明确本期基准（沪深300，价格指数口径）与有效主动风险预算额度；**没有基准，一切超配/低配都是没有度量单位的形容词**。基准口径三声明：价格指数≠全收益（低估股息，不得记为 α）、现金是约束代价非判断失误、口径不得事后切换。
2. **结论先行**：开篇给一句话判断，再展开证据；每个判断挂一个量化锚。
3. **层层递进不罗列**：观点之间呈现推导关系，每层结尾给「本层结论」并自然引出下一层；禁止「观点 A；观点 B；观点 C」式的罗列。
4. **六步组织**：市场观点类产出按「钱从哪来 → 钱变利润 → 价格装多少预期 → 结构定价自洽 → 周期定位风险归属 → 错了会怎样」递进。
5. **方法论内化**：正文不得出现书名、作者名、「某书认为」等书目痕迹；方法只用于判断，不作为可见内容。文末「方法论说明」只描述本人分析流程。
6. **两个强制独立章节**：市场观点类产出必须含「上期判断回顾」（逐条标注已验证/未验证/证伪 + 累计命中率，不用短期损益贴标签）与「方法可靠性声明」（显式声明局限）。
7. **主动收益落账**：任何偏离须写成主动权重向量 w_a（Σw_a,i=0），用协方差口径 σ_A 精算，给出 E[R_A] 三项分解与净预期主动收益——**禁止只给方向不给数**。

## §2 数据要求（怎么用数）

1. **口径锚定**：宏观数字先读对——名义/实际、同比/环比、结构拆解、基数与季节性；锚定官方口径。
2. **四级数据标注**：每个非引用数字必须落到一级——`测算`（模型算，给参数）/ `估算`（量级推断）/ `研判推断`（分析性判断）/ `待补`（进观察清单）。
3. **来源可点击**：引用数据/观点挂来源链接，严禁编造；券商观点只作对照组，给出「认同/保留/反对及理由」。
4. **一手自算**：行情用公开 K 线自算四档分位、波动、回撤、相关矩阵、拥挤度（三条腿：成交额占比/持有人结构/收益同步）、风险贡献分解；估值分位若用外部口径必须标注来源。
5. **实施成本五度量法**：佣金 + 买卖价差 + 价格冲击（平方根律，主导项）+ 延迟/机会成本 + 税费，落账用 IS=TC+OC；**只算佣金 = 未通过**。
6. **海外锚重标定**：海外实证数值只作数量级参考，A 股须重新标定，严禁当默认判据。
7. **铁律：编数字比不回答更严重**；数据不可得 → 如实标「待补」进观察清单。
8. **量纲与口径交叉校验**：外部行情/金融数据字段用于绝对额结论前，必须先与权威口径做比例校验；同一字段比例漂移 >5% 时，绝对额一律改用交易所/官方口径，外部字段只用于比值、分位和方向判断。

## §3 质量门禁（怎么过关）

1. **两道横切闸门**（硬门，所有结论强制生效）：
   - **闸门 A · 统计可信**：t 阈值按检验类型分档（时序回归 ≥3.8 / Fama-MacBeth ≥3.4 / 单向检验 ≥3.0，2.0 不可用）；同一数据多假设须做**多重检验校正（BH-FDR q=0.10 + Bonferroni）**并报「假设总数 / 原始 p<0.05 数 / 校正后存活数」；校正后不显著只写「证据不足，两个方向都不支持」，**禁止反向解读**；样本 <10 年降级为提示性观察；回测夏普按 **Haircut Sharpe + Deflated Sharpe 双口径**取较严者；胜率断言须同报原始/非重叠/月频单期重叠三类样本数；**闸门 A 正反双校准**（v24 起）——正向按 Haircut/Deflated Sharpe 双口径取较严者，反向依发表偏误仅需收缩 10–15%（FDR<10%），**未过校正只写「证据不足，两个方向都不支持」，禁止反向宣称因子无效／反向信号成立**；**分层凯利**——下注上限 2P−1 的 P 按可预测性聚类取用，高可预测聚类用实证分层 P，低可预测资产 P 收敛 0.50（上限 0）。
   - **闸门 B · 实施成本与可执行**：任何超配/低配/轮动/调仓须给出 `E[R_A] __ bp − 实施成本 __ bp = 净预期主动收益 __ bp`，**净额 ≤ 0 不发布**；成本五度量法（佣金/价差/冲击/延迟/税费，IS=TC+OC）；声明 ADV 容量（10%）与适用资金规模上限；多空因子按不能做空折损 50%–60% 打折；拥挤度三条腿极端时附退出触发条件；**主动风险须在事前档位额度内（协方差口径精算，禁止简单加总），超额度只能缩幅度或降级观察**。
2. **起步门禁**（见 `quality-policies/baseline.json`）：禁例 token 0 命中、占位符 0 残留、数字逐 token 一致、渲染 0 溢出 + 对比度 AA、排版审计 0 问题、章节大纲对照输出模板、配置结论净预期主动收益 > 0。
3. **摘要—正文—底座三方对撞**：摘要中的每条概括必须在正文找到对应论据、并在数据底座找到同口径证据；三方不一致时不得发布，先回底座查错。参考实现：`references/scripts/i1_collision_check.py --md <report.md> --pool <data.json> ... --out <i1-report.json>`。
4. **合规红线**：对外匿名呈现（领域·首字母）；文末固定「不构成投资建议」；未发布官方数据显式标注「尚未发布」；渲染产物发布为公网外链前，先确认内容不涉密、可公开；A 股因子实证基线窗口 2000-01~2019-12 须标注并声明滚动复核。
5. **交付前逐项过** `references/checklist-template.md`。
