# 宏观与资本市场分析工艺

> 一句话总纲：结论先行、层层递进、逐条可核验；无测算不下结论，净 α ≤ 0 不发布。

## §0 模板引用（先读）

- 方法包 `method-packs/six-step-internalization.json`：六步内化流程（权威步骤定义）。
- 方法包 `method-packs/nine-layer-framework.json`：九层能力框架（机制支撑来源）。
- 方法包 `method-packs/dual-gates.json`：两道横切闸门（数字与可执行性硬门）。
- 输出模板 `output-templates/a-share-outlook.json` / `cycle-positioning.json`：交付物骨架。

本文件只规定执行规则，不重复上述实体内容。

## §1 行文逻辑（怎么写）

1. **结论先行**：开篇给一句话判断，再展开证据。
2. **层层递进不罗列**：观点之间呈现推导关系，每层结尾给「本层结论」并自然引出下一层；禁止「观点 A；观点 B；观点 C」式的罗列。
3. **六步组织**：市场观点类产出按「钱从哪来 → 钱变利润 → 价格装多少预期 → 结构定价自洽 → 周期定位风险归属 → 错了会怎样」递进。
4. **方法论内化**：正文不得出现书名、作者名、「某书认为」等书目痕迹；方法只用于判断，不作为可见内容。文末「方法论说明」只描述本人分析流程。
5. **两个强制独立章节**：市场观点类产出必须含「上期判断回顾」（逐条标注已验证/未验证/证伪 + 累计命中率）与「方法可靠性声明」（显式声明局限）。

## §2 数据要求（怎么用数）

1. **口径锚定**：宏观数字先读对——名义/实际、同比/环比、结构拆解、基数与季节性；锚定官方口径。
2. **四级数据标注**：每个非引用数字必须落到一级——`测算`（模型算，给参数）/ `估算`（量级推断）/ `研判推断`（分析性判断）/ `待补`（进观察清单）。
3. **来源可点击**：引用数据/观点挂来源链接，严禁编造；券商观点只作对照组，给出「认同/保留/反对及理由」。
4. **一手自算**：行情用公开 K 线自算四档分位、波动、回撤、相关矩阵、拥挤度、风险贡献分解；估值分位若用外部口径必须标注来源。
5. **海外锚重标定**：海外实证数值只作数量级参考，A 股须重新标定，严禁当默认判据。

## §3 质量门禁（怎么过关）

1. **两道横切闸门**（硬门，所有结论强制生效）：闸门 A 统计可信（t 阈值分档 / 样本量 / 夏普 50% 折 / 肥尾禁用正态外推）；闸门 B 摩擦可执行（毛 α − 摩擦 = 净 α，净 α ≤ 0 不发布）。
2. **五道起步门禁**（见 `quality-policies/baseline.json`）：禁例 token 0 命中、数字逐 token 一致、渲染 0 溢出 + 对比度 AA、排版审计 0 问题、章节大纲对照输出模板。
3. **合规红线**：对外匿名呈现（领域·首字母）；文末固定「不构成投资建议」；未发布官方数据显式标注「尚未发布」。
