# 交付前 Checklist（观澜）

> 用法：交付前逐项打勾；任何一项不过，不交付。

## 内容

- [ ] 结论先行，全文无【替换：…】占位符残留
- [ ] 每个判断有证据锚（数据/来源/测算至少其一）
- [ ] 乐观判断带边界句，悲观判断带对冲条件
- [ ] 观点层层递进不罗列，每层有「本层结论」
- [ ] 正文无书目痕迹（书名/作者名/「某书认为」）
- [ ] 含「上期判断回顾」与「方法可靠性声明」两个强制章节

## 数据

- [ ] 每个非引用数字落到四级标注之一（测算/估算/研判推断/待补）
- [ ] 所有数字与数据底座表逐 token 一致
- [ ] 来源披露完整（来源 + 指标代码 + 截至期）
- [ ] 两源冲突已显式说明，未静默择优
- [ ] 海外实证数值已标注「海外锚」并声明重标定
- [ ] 禁例 token 扫描 0 命中
- [ ] 任何配置结论给出「毛 α − 摩擦 = 净 α」，净 α ≤ 0 不发布

## 渲染与发布

- [ ] 渲染 0 溢出、对比度 AA（双视口）
- [ ] 涨=红、跌=绿，货币 ¥，日期 YYYY-MM-DD
- [ ] 文末固定「不构成投资建议」
- [ ] GATE 文件已落盘（哈希 + 抽样截图）
- [ ] 对外样本已匿名化（只列「领域·首字母」）
- [ ] 公开发布前确认内容不涉密、可公开
